## DOODLE GUESSER using Google Quick Draw Dataset and Pytorch 
I just wanted to learn and have fun while making project, thats why i made this project 
If you wanna run the project
For mac 
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
For Windows
```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
python app.py
```
#### Some Technical Details 
- Pytorch Custom CNN for Model 
- Scikit-Learn Train Test Split 
- Google Quick Draw Dataset (Chunk of the dataset)
- Run over 5 epochs with about 93% test accuracy
- 10 classes namely airplane, bicycle, cat, car, dog, fish, house, sun, tree, umbrella
